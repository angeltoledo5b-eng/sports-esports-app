# 🏆 SportsHub - Red Social & Gestión de Torneos

Plataforma web moderna construida para apasionados de los deportes y eSports. Permite conectar comunidades, publicar novedades, organizar torneos con llaves de eliminación (brackets) y gestionar equipos.

## 🚀 Tecnologías Utilizadas

* **Frontend:** Next.js (App Router), React, TypeScript.
* **Estilos:** Tailwind CSS.
* **Backend & Base de Datos:** Supabase (PostgreSQL, Supabase Auth, Row Level Security).
* **Despliegue:** Vercel.

## ⚡ Características Principales

* 💬 **Feed Social Dinámico:** Publicaciones por disciplina (Wild Rift, Fútbol 5, etc.), likes y comentarios en tiempo real.
* 🔐 **Autenticación Integrada:** Inicio de sesión y registro de usuarios con Supabase Auth.
* 🏆 **Gestión de Torneos:** Registro de competencias, filtros por estado, seguimiento de cupos e inscripción directa.
* 📊 **Brackets Interactivos:** Visualización gráfica del árbol de eliminatorias (cuartos, semifinales y gran final).
* 🛡️ **Equipos & Guilds:** Creación de clubes/escuadras, asignación de TAGs y reclutamiento.
* 👤 **Perfil de Jugador:** Panel con estadísticas y torneos activos.
